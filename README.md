# WORKNA

WORKNA brings work opportunities, freelance services and physical products together in one trusted platform. Built for Nigeria and designed to grow globally.

## Product
- Discover and buy products from independent sellers.
- Hire professionals and publish fixed-price projects.
- Build a freelancer profile, submit proposals and collaborate with clients.
- Manage orders, conversations, earnings and payouts.

## Stack
Next.js App Router, TypeScript, Supabase, Tailwind CSS and Vercel.

See [WORKNA_FEATURES.md](./WORKNA_FEATURES.md) for the capability roadmap and [WORKNA_PAYMENTS_SETUP.md](./WORKNA_PAYMENTS_SETUP.md) for payment integration requirements.
